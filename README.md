# 家トレ減量 30 DAYS

GitHub Pagesでそのまま公開できるPWAです。

## 公開方法
1. GitHubで新しいリポジトリを作成
2. このZIPの中身をすべてリポジトリ直下へアップロード
3. GitHubの Settings → Pages
4. Build and deployment で Deploy from a branch
5. Branch を main / (root) に設定して Save
6. 公開URLをiPhoneのSafariで開く
7. 共有ボタン → ホーム画面に追加

## 入っている機能
- 曜日ごとの家トレメニュー
- 3週目から自動負荷アップ
- 完了チェック
- 週間達成率
- 連続達成日数
- 運動消費カロリー目安
- 体重・腹囲記録
- 目標体重までの差
- 30件の体重グラフ
- 歩数・水分・間食・夕食満腹度の記録
- 60秒休憩タイマー
- オフライン対応
- iPhoneホーム画面追加対応

データはブラウザのlocalStorageに保存されます。
